# PlayStation 1 BIOS

Para rodar jogos de PlayStation 1 (PS1) neste emulador, você precisa colocar o arquivo de BIOS oficial aqui.

## Como instalar:

1. Obtenha o arquivo de BIOS oficial com o nome: **`scph5501.bin`** (BIOS americana oficial do PS1, com exatamente **512 KB** ou **524.288 bytes**).
2. Cole o arquivo `scph5501.bin` nesta pasta `/bios/`.
3. Certifique-se de que o nome está exatamente em minúsculas: `scph5501.bin`.
4. Recarregue o emulador no navegador.
